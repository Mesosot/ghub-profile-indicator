# G HUB Profile Indicator 1.0.0

A lightweight Windows indicator that reads the effective profile directly from the running Logitech G HUB agent.

## Download and run

Download `GHubIndicator-Windows-x64.zip`, extract it, and double-click `GHubIndicator.exe`. Keep G HUB running in the background. Python and administrator rights are not required.

Drag the overlay to move it; right-click or use the dots menu for tray controls and optional notifications.

## Compatibility

Verified on Windows 11 x64 with G HUB 2026.7.1011216, including Desktop/Tibia automatic profile switching.

The app uses a verified private G HUB interface, not an officially supported Logitech API. Future G HUB updates may require a compatibility update. It reports software profile state, not onboard physical-device settings. Exclusive fullscreen games may cover the overlay.

The executable is unsigned. The source, build instructions, SHA-256 checksum and third-party license notices are included or supplied alongside this release.
